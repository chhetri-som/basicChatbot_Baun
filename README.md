# Chatbot Baun

The chatbot implemented is a very basic predictive ai chatbot, with an extremely limited
and basic dataset. The following libraries were downloaded in an environment created in Anaconda:
- Python 3.6
- Numpy
- Tflearn
- Tensorflow-gpu 1.15
- NLTK
- CudaToolkit 11.0
- cuDNN 8.04

The program runs in the terminal, you can you cmd prompt, bash, powershell, anaconda nav, etc.

Dataset used in the intents.json file is from kaggle,
